# GitHub Pages CV

## How to publish
1. Create a public repository named `NicolasAraya932.github.io`
2. Upload `index.html` and `styles.css`
3. Commit and push to `main`
4. Your site will appear at `https://NicolasAraya932.github.io`

## Quick customization
- Edit the text inside `index.html`
- Change colors in `styles.css`
- Add a PDF CV button by linking to a file like `cv_nicolas_araya_en.pdf`
